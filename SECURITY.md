# Security Policy

## Scope

Security vulnerabilities in VPS Shield itself are in scope. Findings caused solely by a user's server configuration are operational findings, not necessarily project vulnerabilities.

## Reporting

Please do not publish exploit details in a public issue before maintainers have had an opportunity to assess the problem. Use GitHub's private vulnerability reporting/security advisory mechanism when available.

Include:
- affected version/commit
- distribution and version
- reproduction steps
- impact
- relevant logs with secrets removed
- proposed mitigation, if known

## Safe testing

Only test against systems you own or are explicitly authorized to assess.

## Security guarantees

VPS Shield reduces attack surface but cannot guarantee compromise prevention. It is not a replacement for backups, application security, provider controls, vulnerability management, monitoring or incident response.
